# StudyPilot 个人学习助手 BRD 业务需求文档

## 1. 文档定位

BRD 回答“该不该做”。本文从业务价值、用户价值、实训价值、成本风险和成功标准角度，判断 StudyPilot 个人学习助手是否值得开发。

## 2. 项目概述

StudyPilot 是一个面向学生的 AI 个人学习助手，围绕课程任务、个人笔记、RAG 问答、复习训练、学习计划和实训报告形成闭环。系统使用本地 SQLite 管理学习数据，使用 Chroma 构建个人笔记向量库，通过多智能体完成任务管理、笔记问答、学习计划、复习训练、学术诚信护栏和报告素材生成。

## 3. 业务背景

当前学生使用 AI 学习工具时常遇到以下问题：

- 学习资料、待办任务、复习题和报告记录分散在不同工具中。
- 通用 AI 回答不一定基于个人课程笔记，容易出现幻觉和假引用。
- 学生容易直接依赖 AI 答案，而不是真正掌握知识。
- 课程实训需要展示 RAG、Agent、工具调用、部署和报告，但普通聊天应用无法体现完整开发能力。

因此，需要一个既能解决真实学习问题，又能体现人工智能应用开发能力的项目。

## 4. 业务目标

| 目标 | 说明 | 衡量方式 |
| --- | --- | --- |
| 提高学习管理效率 | 将任务、笔记、复习、周报集中管理 | 用户能在首页看到今日任务和计划 |
| 提升 AI 回答可信度 | 基于个人笔记 RAG 回答并展示来源 | 每次问答展示来源卡片和可信度 |
| 形成学习闭环 | 从记录、问答、测验、错题到复盘 | 能生成闪卡、错题和学习周报 |
| 满足实训评分 | 覆盖 RAG、Agent、工具、部署、文档 | 报告与演示材料完整 |
| 增加创新亮点 | 学术诚信护栏、专注模式、报告素材库 | 答辩可展示差异化功能 |

## 5. 目标用户

| 用户 | 业务价值 |
| --- | --- |
| 实训学生 | 完成课程实训项目，提升报告质量和答辩表现 |
| 普通大学生/高职学生 | 管理课程任务、复习笔记和学习计划 |
| 指导教师/评委 | 看到清晰的 AI 应用开发能力和完整项目设计 |

## 6. 核心业务价值

### 6.1 对学生

- 减少忘记作业、复习无计划的问题。
- 用个人笔记生成可信回答，降低 AI 幻觉影响。
- 通过闪卡、测验、错题本提升复习效率。
- 自动沉淀学习过程，降低写实训报告的压力。

### 6.2 对课程实训

- 覆盖 RAG、Embedding、向量库、SQLite、LLM、Agent、UI、部署。
- 可展示多个功能截图，报告内容更完整。
- 项目主题贴合“人工智能应用开发技术”。

### 6.3 对产品长期发展

- 可扩展到更多课程、PDF 资料、多人共享题库、学习周报导出。
- 可形成“本地化、可信、反依赖”的学习助手差异化定位。

## 7. 范围边界

### 7.1 本期范围

- 个人学习数据导入。
- 自然语言任务管理。
- 基于个人笔记的 RAG 问答。
- 学习计划生成。
- 闪卡/测验/错题记录。
- NiceGUI 学习驾驶舱。
- 来源可信度、学术诚信、隐私提示。
- 实训报告素材辅助生成。

### 7.2 暂不做

- 多用户账号系统。
- 移动端原生 App。
- 班级级共享知识库。
- 完整 LMS 教务系统。
- 复杂支付、商业化、权限体系。

## 8. 成本与可行性

| 维度 | 判断 |
| --- | --- |
| 技术可行性 | Python + SQLite + Chroma + LLM API + NiceGUI 可实现 |
| 时间可行性 | MVP 可按 5 天实训周期拆解完成 |
| 数据可行性 | 使用学生自己的 Excel 待办和笔记即可启动 |
| 成本可控性 | 主要成本为 LLM API 调用，数据本地存储 |
| 风险可控性 | 通过 Gradio fallback、演示数据、项目健康检查降低演示风险 |

## 9. 风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| LLM API 不稳定 | 影响问答和意图解析 | 增加错误提示、备用模型、演示数据 |
| 笔记数据太少 | RAG 效果差 | 增加资料质量检查和补充建议 |
| 功能范围过大 | 5 天内做不完 | 分 P0/P1/P2，优先实现核心闭环 |
| UI 开发超时 | 影响展示 | NiceGUI 主界面 + Gradio 保底 demo |
| 学术诚信争议 | 用户直接让 AI 代写 | IntegrityAgent 做护栏 |

## 10. 成功标准

| 类型 | 标准 |
| --- | --- |
| 必须成功 | 能导入数据、问笔记、添加任务、生成计划 |
| 应该成功 | 能显示来源引用、生成闪卡/测验、记录错题 |
| 加分成功 | 有学习驾驶舱、学术诚信护栏、报告素材生成 |
| 展示成功 | 能完成 5 分钟演示和至少 5 张截图 |

## 11. 业务结论

StudyPilot 值得开发。它不仅满足实训指导书中案例B的基础要求，还能通过 NiceGUI 学习驾驶舱、可信 RAG、复习训练、学术诚信护栏和实训报告素材库形成差异化。项目成本可控、技术路径清晰、展示价值强，适合作为人工智能应用开发技术实训项目。
