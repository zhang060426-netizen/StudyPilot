FSD 细化功能操作步骤、输入输出、规则和异常处理，回答“功能具体怎么用、怎么验收”。

## 3. F01 数据导入与初始化

### 输入

- `data/todo.xlsx`
- `data/notes.xlsx`

### 操作步骤

1. 用户进入“资料库设置”页面。
2. 点击“导入 Excel 数据”。
3. 系统读取待办表和笔记表。
4. 系统写入 SQLite。
5. 用户点击“重建向量库”。
6. 系统读取笔记、分块、向量化并写入 Chroma。

### 输出

- `learning.db`
- `note_vector_db/`
- 导入成功提示。

### 异常

| 异常 | 处理 |
| --- | --- |
| Excel 缺字段 | 提示缺少字段名 |
| 笔记为空 | 提示补充内容 |
| 向量库失败 | 提示删除旧索引并重建 |

## 4. F02 自然语言任务管理

### 输入

用户自然语言，如“下周一交 Python 作业”。

### 操作步骤

1. 用户在任务管理页输入任务。
2. 系统调用 `parse_intent()`。
3. 页面展示解析预览：course、task、deadline、priority。
4. 用户确认或直接保存。
5. TaskAgent 写入/更新 SQLite。

### 输出

- 任务表新增或更新记录。
- 页面刷新任务列表。

### 规则

- 未识别课程时默认 `未分类`。
- 未识别截止日期时要求用户补充。
- 已完成任务不可重复完成。

## 5. F03 AI 问笔记 RAG

### 输入

- 用户问题。
- 可选课程范围。

### 操作步骤

1. 用户选择课程或“全部课程”。
2. 输入问题。
3. NoteAgent 调用 RAG 检索。
4. 系统返回 Top-K 笔记片段。
5. LLM 基于上下文生成回答。
6. UI 展示答案、来源引用和可信度。

### 输出

- 答案文本。
- 来源卡片：课程、标题、片段、相似度。
- 可信度：高可信/部分可信/来源不足。

### 异常

- 如果无来源，提示用户补充笔记。
- 如果 API 超时，提示重试或切换备用模型。

## 6. F04 学习计划生成

### 输入

- 未完成任务。
- deadline。
- 错题和掌握度。
- 用户可选学习时长。

### 操作步骤

1. 用户点击“生成今日计划”。
2. PlanAgent 查询任务和复习记录。
3. 系统计算优先级。
4. LLM 生成上午/下午/晚上计划。
5. UI 展示计划和建议。

### 输出

- 今日三段式计划。
- 优先任务。
- 复习建议。

## 7. F05 闪卡/测验生成

### 输入

- 课程。
- 笔记范围。
- 题目数量。
- 题型。

### 操作步骤

1. 用户进入复习训练。
2. 选择课程和题型。
3. QuizAgent 调用 RAG 获取笔记片段。
4. LLM 生成题目、答案、解析。
5. 用户作答。
6. 系统记录结果。

### 输出

- 闪卡或测验题。
- 正确率。
- 错题记录。

## 8. F06 错题本与掌握度

### 规则

- 答错一次，知识点掌握度降低。
- 连续答对两次，掌握度提高。
- 每道错题保留原始笔记来源。

### 输出

- 错题列表。
- 知识点掌握状态。
- 下次复习建议。

## 9. F07 专注学习会话

### 操作步骤

1. 用户从任务列表选择一个任务。
2. 点击“开始专注”。
3. 系统展示目标、相关笔记和计时器。
4. 结束后用户填写完成情况和卡点。
5. 系统写入 `study_sessions`。

## 10. F08 学术诚信护栏

### 触发条件

- “直接帮我写完整报告”
- “替我完成作业”
- “直接给可提交答案”

### 处理方式

- 不直接输出完整可提交内容。
- 提供思路、提纲、步骤、检查清单。
- 鼓励用户补充自己的实践内容。

## 11. F09 隐私安全检查

### 检查内容

- API Key。
- 手机号。
- 邮箱。
- 学号/姓名组合。

### 输出

- 风险提示。
- 清理建议。

## 12. F10 实训报告素材库

### 生成内容

- 每日工作记录。
- 问题与解决方法。
- 核心代码说明。
- 截图清单。
- 实训总结草稿。

## 13. F11 项目健康检查

### 检查项

| 检查项 | 通过标准 |
| --- | --- |
| SQLite 数据库 | 文件存在且表可查询 |
| Chroma 向量库 | 索引存在且可检索 |
| API Key | 环境变量存在 |
| 核心依赖 | NiceGUI、pandas、chromadb 等可导入 |
| 演示数据 | 至少 10 条待办和 10 条笔记 |
