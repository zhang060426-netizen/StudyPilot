## 2. 业务流程图

### 2.1 学习闭环流程

```mermaid
flowchart TD
    A["导入待办和笔记"] --> B["构建 SQLite 和 Chroma"]
    B --> C["查看学习驾驶舱"]
    C --> D["生成今日计划"]
    D --> E["开启专注学习"]
    E --> F["AI 问笔记"]
    F --> G["查看来源引用"]
    G --> H["生成闪卡/测验"]
    H --> I["记录错题和掌握度"]
    I --> J["生成学习周报/报告素材"]
    J --> C
```

### 2.2 RAG 问答流程

```mermaid
flowchart TD
    A["用户提问"] --> B["选择课程范围"]
    B --> C["问题改写"]
    C --> D["向量检索 Top-K"]
    D --> E{"来源是否充分"}
    E -- 否 --> F["提示来源不足/建议补充笔记"]
    E -- 是 --> G["拼接上下文"]
    G --> H["LLM 生成回答"]
    H --> I["展示答案 + 来源 + 可信度"]
```

### 2.3 任务计划流程

```mermaid
flowchart TD
    A["读取未完成任务"] --> B["计算 deadline 紧急度"]
    B --> C["读取错题和掌握度"]
    C --> D["计算优先级"]
    D --> E["生成上午/下午/晚上计划"]
    E --> F["写入学习日志"]
```

## 4. 状态流转图

### 4.1 任务状态

```mermaid
stateDiagram-v2
    [*] --> 未完成
    未完成 --> 进行中: 开启专注会话
    进行中 --> 已完成: 标记完成
    未完成 --> 逾期: 超过deadline
    逾期 --> 已完成: 补交/完成
```

### 4.2 掌握度状态

```mermaid
stateDiagram-v2
    [*] --> 未学习
    未学习 --> 模糊: 初次答错
    未学习 --> 熟悉: 初次答对
    模糊 --> 需复习: 连续答错
    模糊 --> 熟悉: 答对
    熟悉 --> 掌握: 连续答对
    掌握 --> 需复习: 长期未复习或答错
    需复习 --> 熟悉: 复习后答对
```
