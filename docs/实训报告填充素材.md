# StudyPilot 实训报告填充素材

## 1. 项目概述

StudyPilot 个人学习助手是一款面向学生的 AI 学习管理应用，主要解决学习任务分散、课程笔记难检索、复习计划缺乏安排、AI 回答缺少来源依据等问题。系统基于个人待办和课程笔记构建 SQLite 数据库，并使用 Chroma 向量库实现个人笔记 RAG 问答。用户可以通过 NiceGUI 学习驾驶舱添加任务、查询知识点、生成今日学习计划、根据笔记生成复习题，并查看项目健康状态。系统采用 MainAgent 统一路由，TaskAgent、NoteAgent、PlanAgent、QuizAgent、ReportAgent 等智能体协同完成不同任务。项目创新点包括来源可信度提示、Chroma + 关键词混合检索、学术诚信护栏、项目健康检查和报告素材辅助，能够形成从记录、问答、训练到复盘的完整学习闭环。

## 2. 技术架构图说明

本项目采用“用户 -> NiceGUI 界面 -> MainAgent 智能体 -> RAG/工具 -> SQLite/Chroma 数据库”的架构。用户通过浏览器访问 NiceGUI 页面，输入自然语言问题或点击功能按钮。MainAgent 调用意图解析模块识别用户意图，并分发给任务管理、笔记问答、学习计划或复习训练智能体。结构化数据保存在 SQLite 中，课程笔记同时构建 Chroma 向量索引。RAG 模块优先使用 Chroma 向量检索，并结合关键词得分进行混合排序，最后根据来源笔记生成回答和可信度提示。

## 3. 每日工作记录建议

### 第 1 天：数据准备

- 完成 `todo.xlsx` 和 `notes.xlsx` 示例数据设计。
- 覆盖 Python、AI 应用开发、英语 3 门课程。
- 每门课程包含至少 5 条待办和 5 条笔记。
- 编写 `scripts/create_sample_data.py` 自动生成演示数据。
- 编写 `src/init_db.py` 将 Excel 导入 SQLite，并创建扩展表。

### 第 2 天：意图解析与任务管理

- 编写 `src/intent.py`，支持添加待办、查看任务、完成任务、查询笔记、生成计划、生成测验等意图。
- 编写 `src/tools.py`，封装 SQLite 增删改查。
- 实现自然语言添加任务，例如“周五前完成 Python 列表推导式作业”。
- 修复“完成作业”被误判为完成已有任务的问题。

### 第 3 天：RAG 问答与向量库

- 编写 `src/note_vector.py` 构建 Chroma 向量库。
- 编写 `src/rag.py` 实现个人笔记检索和回答生成。
- 增加 Chroma + 关键词混合检索，提升中文课程笔记命中率。
- 实现来源引用和可信度提示。

### 第 4 天：多智能体与复习训练

- 编写 `src/agents.py`，实现 MainAgent、TaskAgent、NoteAgent、PlanAgent、QuizAgent、ReportAgent。
- 实现今日学习计划生成。
- 实现根据课程笔记生成复习题。
- 编写 `src/safety.py` 实现学术诚信护栏。

### 第 5 天：界面、部署与验证

- 使用 NiceGUI 实现学习驾驶舱、AI 问笔记、任务管理、复习训练、学习周报和项目健康检查。
- 编写 `scripts/smoke_test.py` 进行核心功能验证。
- 安装 NiceGUI、OpenAI SDK、websocket-client、Chroma。
- 启动本地服务并通过 `http://127.0.0.1:8080` 访问。

## 6. 问题与反思

本项目遇到的主要困难是如何让 AI 回答既自然又可信。最初只使用关键词检索时，回答虽然能运行，但检索效果不够稳定；接入 Chroma 后，向量检索可以表达语义相似度，但默认模型对中文短问句有时排序不够理想。因此项目采用 Chroma + 关键词混合检索的方式，提高个人笔记命中率。另一个问题是不同 API 的鉴权方式不同，DeepSeek 使用 OpenAI 兼容接口，而讯飞星火截图中提供的是 WebSocket 鉴权信息，需要单独实现签名连接。通过本次实训，我认识到 AI 应用开发不仅是调用模型接口，更重要的是数据组织、检索质量、异常兜底、用户界面和演示稳定性。

## 7. 实训总结

通过 StudyPilot 项目，我完整实践了 AI 应用开发的基本流程：从需求分析、竞品调研、PRD/BRD/MRD 设计，到数据建模、SQLite 数据库、Chroma 向量库、RAG 问答、多智能体路由和 NiceGUI 前端界面。项目让我理解到，真正有价值的 AI 应用不只是让大模型回答问题，而是要围绕真实用户场景构建完整闭环。本项目通过个人笔记 RAG、来源引用、学习计划、复习训练和项目健康检查，把学习数据转化为可查询、可复习、可展示的智能系统，也让我对 AI 工程中的数据质量、可解释性和用户体验有了更深入的认识。
